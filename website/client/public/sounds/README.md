# Custom Khmer Voice & Sound Files

Place your custom audio files in this folder (`website/client/public/sounds/`):

1. **`order-success.mp3`** (or `.wav` / `.m4a`):
   - Voice: *"ការបញ្ជាទិញរបស់អ្នកទទួលបានជោគជ័យ!"* (Your order has been placed successfully!)
   - Plays automatically when the user clicks **Place Order**.

2. **`payment-success.mp3`** (or `.wav` / `.m4a`):
   - Voice: *"ការទូទាត់ប្រាក់របស់អ្នកទទួលបានជោគជ័យ!"* (Your payment was successful!)
   - Plays automatically when ABA PayWay payment is approved.

### Note:
- Supported formats: `.mp3`, `.wav`, `.m4a`, `.ogg`.
- If an audio file is not present in this folder, the system automatically falls back to browser text-to-speech.
